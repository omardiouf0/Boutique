# Boutique — E-Commerce Fullstack

Application e-commerce complète avec Frontend (React + Vite) et Backend (Python FastAPI / Node.js).

## Structure du Projet
- `backend/` : API FastAPI avec authentification JWT, gestion des produits, catégories, commandes et paiements.
- `frontend/` : Application SPA React, Vite, Tailwind CSS et dashboard admin.
